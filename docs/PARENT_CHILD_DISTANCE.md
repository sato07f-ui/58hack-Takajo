# 見守りモード（親子距離・脱出と復活） 使い方と制約

実装手順は [PARENT_CHILD_DISTANCE_PLAN.md](PARENT_CHILD_DISTANCE_PLAN.md) を参照。

## できること
- 親のスマホで、子供が何 m 離れているかをリアルタイムに見られる
- 子供が親から **50 m 超** 離れた状態が **5 秒** 続くと「ダンジョンから脱出」状態になり、ゲーム操作ができなくなる
- 脱出中の子供が親の **10 m 以内** に **3 秒** 留まると、親の端末から「復活の鍵」が自動で届いてゲームに戻れる
- 親との通信が **30 秒** 途切れた場合も安全側に倒して脱出状態になる

## 使い方
1. 親子が一緒にいる状態で、両方の端末でアプリを開き「見守りモード」を選ぶ
2. **親**: 「親として使う」→ 復活の鍵になるコード（英数字 6〜12 文字）を決めて「冒険をはじめる」
3. **子供**: 「子供として使う」→ 親に教えてもらったコードを入力して「冒険をはじめる」。以後コードは画面に出ない
4. **子供**: 「ダンジョンへ入る」で AR ゲームが開く。画面上部に親までの距離が出る
5. 離れすぎると子供の画面に脱出画面が重なり、親の画面に警告が出る。親に近づくと復活する

位置情報・カメラ・向きセンサーの許可はすべてボタンのタップ時に求められる。拒否した場合は画面に設定手順が出る。

## 仕組み
| 役割 | 使うもの |
|---|---|
| 位置の取得 | Geolocation API `watchPosition`（誤差 100 m 超の測位は捨てる）|
| 親子間の通信 | Supabase Realtime の Broadcast / Presence（DB は使わない）|
| ペアリング | 親が決めたコードをチャンネル名（`tracker:<コード>`）にする |
| 距離 | Haversine 公式（`src/utils/tracker/haversine.js`）|
| 復活の鍵 | 親が決めたコードそのもの。親端末が距離を判定して `revive` イベントで送り、子供はコード一致で復活 |

Broadcast はサーバーに保存されないため、位置は 10 秒ごとに再送し、脱出中は 5 秒ごとに脱出を再通知する。これにより途中で入室・再接続した相手にも状態が伝わる。

### しきい値（`src/utils/tracker/escapeRules.js`）
| 定数 | 値 | 意味 |
|---|---|---|
| `ESCAPE_DISTANCE_M` / `ESCAPE_HOLD_MS` | 50 m / 5 秒 | 脱出の条件 |
| `REVIVE_DISTANCE_M` / `REVIVE_HOLD_MS` | 10 m / 3 秒 | 復活の条件 |
| `MAX_JUDGE_ACCURACY_M` | 50 m | 親子の誤差の合計がこれを超える間は判定を保留 |
| `STALE_AFTER_MS`（useLocationChannel） | 30 秒 | 通信途絶の判定 |

脱出と復活で距離を分けているのは、GPS の揺れで状態が行き来しないようにするため（ヒステリシス）。値はすべて仮で、実機で歩いて調整する。

## 制約・注意
- **屋内・ビル街では精度が落ちる。** 誤差 20〜50 m は普通に出る。スーパーの店内では距離がほぼ当てにならないので、店の外や広い駐車場でのデモを推奨
- **バックグラウンドでは動かない。** 子供がブラウザを閉じる・別アプリに切り替えると位置が送られなくなる。Screen Wake Lock で画面のスリープは防ぐが、アプリの切り替えは防げない。30 秒で通信途絶 → 脱出になる
- **iOS Safari は Wake Lock が 16.4 以降。** 古い端末では画面が消えると送信が止まる
- **認証なし。** コードを知っていれば誰でも同じチャンネルに入れる。同じ役割が重複した場合は後から入った側にエラーを出す
- **HTTPS 必須。** 位置情報は HTTPS でしか取れない（`npm run tunnel` で確認できる）
- 距離の判定は端末の時計に依存しない（受信時刻を使う）が、位置の `ts` は端末時刻なので表示には使っていない

## 環境変数
```
VITE_SUPABASE_URL=
VITE_SUPABASE_PUBLISHABLE_KEY=
```
Supabase ダッシュボードの「Connect」または Project Settings › API Keys から取得し、`.env.local` に書く。デプロイ時はビルド用の環境変数として同じ 2 つを登録する。

## 動作確認
- PC: `npm run dev` を 2 タブで開き、DevTools › Sensors で片方の位置を変える
- 実機: `npm run tunnel` の URL を iPhone / Android で開き、屋外で歩く
- 自動テスト（Playwright）で確認済みのシナリオ: 近い/中/遠の色分け、コード重複のエラー、通信途絶、脱出→復活、親の再接続後の復活
